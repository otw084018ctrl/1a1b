# 1A1B 連線對戰

雙人連線的 1A1B 猜數字，含簡單模式、回合計時、房間列表、邀請連結與聊天室。零依賴，只需 Node.js 18 以上。

## 本機 / 同一個 Wi-Fi

```
node 1a1b-server.js
```

Windows 可以直接雙擊 `start.bat`。啟動後打開終端機顯示的網址。

## 部署（Render）

New → Web Service → 選這個 repository，Start Command 填 `npm start`，方案選 Free。

## 記憶撲克（beta）

大廳開房間時玩法選「記憶撲克 β」，2–4 人。

1. 16 張牌正面朝上 10／20／30 秒（房主設定），記住位置。
2. 牌翻回去，公布 3 張公牌；60 秒內點牌背放上蠟印，選 2 張並鎖定。
3. 全員鎖定後亮出所有人的蠟印，再翻牌，用「自己的 2 張＋3 張公牌」比標準撲克牌型。
4. 平手自動重打；選牌逾時的人判負。

牌型判斷在 `poker.js`，測試：`node poker.test.js`。
